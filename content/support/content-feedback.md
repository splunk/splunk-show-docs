<!-- # Content Issues (Submit Content Feedback) -->

If you have a question or issue with demo/workshop content - e.g. "the demo script has incorrect screenshots" or "the slide deck has a mistake on it", etc. - you can submit content feedback directly to the content owner by clicking into any demo or workshop template and clicking on the **Submit Content Feedback** button.

<figure style="max-width: 80%; margin: 0 0 1rem 0;">
  <img src="/splunk-show-docs/images/content_feedback_button.png" alt="Submit Content Feedback button" style="width: 100%; height: auto; display: block; margin: 0;">
  <figcaption style="text-align: center; font-size: 0.9em; color: var(--MENU-SECTIONS-LINK-color); margin-top: 0.5rem; font-style: italic;">
    Submit Content Feedback button
  </figcaption>
</figure>

On the popup **Send Feedback** window, enter your content feedback and click on **Send** to submit it to the content owner.

<figure style="max-width: 60%; margin: 0 0 1rem 0;">
  <img src="/splunk-show-docs/images/send_feedback.png" alt="Please provide a brief description of the content issue you found" style="width: 100%; height: auto; display: block; margin: 0;">
  <figcaption style="text-align: center; font-size: 0.9em; color: var(--MENU-SECTIONS-LINK-color); margin-top: 0.5rem; font-style: italic;">
    Please provide a brief description of the content issue you found
  </figcaption>
</figure>

{{% notice style="info" title="Got a Technical Issue with a Running Instance?" %}}
Technical issues related to the running of your demo/workshop - such as instances not spinning up or data not appearing in a specific instance - should be raised as a support request (see [Infrastructure Issues](/support/infrastructure/).)
{{% /notice %}}
